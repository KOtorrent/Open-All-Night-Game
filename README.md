# Open All Night

Browser-first indie horror game rebuild using the standalone PlayCanvas Engine with TypeScript and Vite.

## Run locally or in GitHub Codespaces

```bash
npm install
npm run dev
```

Open the forwarded Vite port (normally 5173).

## Production build

```bash
npm run build
```

## Project safety rule

GitHub is the source of truth. Do not keep meaningful work only inside an AI sandbox or temporary container.

See `PROJECT_STATE.md` for the current milestone and next work.
